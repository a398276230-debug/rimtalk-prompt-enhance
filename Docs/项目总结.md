# RimTalk 增强提示词 - 项目总结 (压缩版)

## 1. 项目目标
增强 RimTalk Mod 发送给AI的上下文信息，使其包含更详细、更具沉浸感的游戏数据。

## 2. 核心功能模块

### 🤖 AI 史官 (AI Historian)
- **每日快照**：每日0点自动记录殖民地建筑/房间/蓝图状态
- **智能差分**：检测新增/减少/拆除的建筑、新增/消失的房间、重新安装/迁移中的设施
- **智能总结**：AI对比昨日快照，融合玩家操作、工程进度、科技状态、当日事件，生成沉浸式日志
- **风格模仿**：模仿玩家概况的语言风格，禁止打破第四面墙
- **历史回溯**：查看过去7天快照，支持一键复制和重新生成
- **自动注入**：可选将快照注入AI上下文（Context/Prompt两种模式）
- **独立API**：支持OpenAI/Gemini/DeepSeek及自定义接口

### 📢 殖民地状况板 (Colony Status Board)
- **多类别**：工程/事件/任务/资源/人员/自定义六大类别
- **结构化追踪**：工程进度条、优先级、状态管理
- **智能注入**：自动格式化为结构化文本注入AI提示
- **高性能UI**：虚拟化渲染，支持海量数据

### ⚡ 自动事件捕获 (Auto Event Capture)
- **全自动捕获**：拦截归档系统，自动捕获信件/任务/消息
- **智能状态追踪**：任务ID关联，自动过期，完成保留
- **智能自动删除**：区分自动捕获/手动创建，分别应用删除策略
- **去重与合并**：自动合并重复事件

### 🏥 健康信息增强
- 严重度百分比、疼痛等级(Mild/Moderate/Severe/Extreme)、致命标记
- 详细描述、智能排序（致命性>疼痛>可见性>严重度）
- **分类过滤**：按类型分别控制显示（仿生体/植入物/伤口/缺失部位/疾病状态）
- **数量限制**：可设置每类hediff的最大显示数量（减少tokens消耗）
- **智能整合**：
  - 伤口整合：同一部位的轻伤合并显示（如"左手: 3处轻伤"）
  - 仿生体摘要：3个以上时显示摘要（如"全面强化(5个仿生体: 双腿、双臂、左眼)"）

### ⚔️ 物品与装备增强
- 装备描述、携带物品、背包物品
- **交互物品**：检测Pawn当前使用的建筑/设备及其描述

### 🤝 派系关系显示
- 智能检测当前地图上的派系，显示关系状态(盟友/中立/敌对)和好感度
- **身份细分**：区分囚犯/敌对分子/访客/商队成员

### 🧠 智能过滤系统
- 泰南语过滤器：跳过高品质物品的"艺术描述"
- 品质阈值、常见物品过滤（原材料/食物/尸体）

### 🗺️ 地图位置信息增强
- **基础位置**：8方位判断、城镇区域(Town Center/Town/Town Edge/Wilderness)
- **自定义命名Area**：独立系统，可视化绘制，智能检测与优先级
- **非主基地支持**：自动识别主/非主基地，显示地图名称和派系信息

### 🏗️ 全局地图布局系统
- 将殖民地房间/区域布局注入System Context
- 按方位智能分组，完整房间名称（含主人名字如"yaowen的卧室"）
- 智能缓存：仅在房间/建筑变化时重新计算

### 🔧 工程施工区域功能
- 框选施工区域，自动扫描蓝图数量
- 自动进度追踪：每日零点更新，100%自动完成
- AI智能总结：根据蓝图内容生成工程名称和描述
- 蓝图与工程关联：自动检测蓝图归属

### ⚔️ 袭击事件追踪
- 战斗统计：敌方(死亡/倒地/撤退/受伤)、殖民者(死亡/倒地/受伤)
- 智能延迟检测(3秒)，自动完成并生成战斗报告

### 🎯 殖民地中心点调整
- 右下角切换按钮，可视化黄色3x3标记
- 支持X/Z轴偏移调整(滑块+输入框)，实时预览

### 🔧 杂项增强
- 解除关系数量限制、解除配角特质限制(Short模式)

## 4. 技术要点
- **Context注入**：Prefix/Postfix拦截ContextBuilder和PromptService方法
  - `PromptService.BuildContext` → 追加殖民地状况信息
  - `ContextBuilder.GetHealthContext` → 增强健康信息
  - `ContextBuilder.GetEquipmentContext` → 增强装备/物品信息
  - `ContextBuilder.GetRelationsContext` → 解除关系数量限制
  - `ContextBuilder.GetTraitsContext` → 解除特质数量限制
  - `ContextBuilder.BuildLocationContext` → 添加相对位置信息
  - `PromptService.DecoratePrompt` → 注入每日快照
- **数据持久化**：GameComponent(ColonyAnnouncementManager)随存档保存
- **UI虚拟化**：动态高度计算，仅渲染可见区域
- **事件捕获**：拦截Archive.Add获取所有游戏事件
- **快照系统**：反射访问RegionGrid.allRooms，基于GenDate.DaysPassed触发
- **性能优化**：事件驱动，无Tick检测，智能缓存

## 5. 编译
- **依赖**：RimTalk.dll (v1.6), Newtonsoft.Json.dll
