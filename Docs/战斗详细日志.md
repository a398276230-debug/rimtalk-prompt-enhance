# 战斗详细日志功能

## 功能概述

RimTalk Enhance 现在支持完整的袭击战斗追踪系统，自动记录并生成战斗报告。

### 输出示例
```
[战斗结束] 敌人(共7人): 击杀7人 | 殖民地无伤亡
[战斗结束] 发狂动物(共12只): 击杀8只, 逃跑4只 | 殖民地: 倒地1, 受伤3
[战斗结束] 虫群(共15只): 击杀15只 | 殖民地: 阵亡1
```

## 技术实现

### 1. 敌对目标识别

使用 RimWorld 内置的 `HostileTo(Faction)` 方法统一判断敌对目标：

```csharp
// Source/Patches/PawnKillPatch.cs
bool isHostileNow = __instance.HostileTo(Faction.OfPlayer);
bool wasDownedEnemy = RaidTrackingService.WasEnemyDowned(__instance.thingIDNumber);
bool isHostileFaction = __instance.Faction?.HostileTo(Faction.OfPlayer) ?? false;

// 综合判断：当前敌对 OR 之前倒地过 OR 属于敌对派系
bool isEnemy = isHostileNow || wasDownedEnemy || isHostileFaction;
```

**支持的敌对类型**：
- ✅ 人类敌人（海盗、部落等）
- ✅ 机械族
- ✅ 发狂动物（Manhunter）
- ✅ 虫群（Infestation）
- ✅ 掠食者（攻击殖民者时）
- ✅ 狂暴状态的 Pawn

### 2. 初始敌人计数

#### 问题
空投/边缘生成时，敌人逐个出现，直接计数会不准确。

#### 解决方案
```csharp
// Source/Services/LordMonitorService.cs
public static void UpdateRaidInitialCount()
{
    // 每秒统计当前敌人数量
    int totalHostile = RaidTrackingService.CountHostileThreats(_subscribedMap);
    
    // 使用最大值策略：只增加不减少
    if (totalHostile > _maxObservedHostileCount)
    {
        _maxObservedHostileCount = totalHostile;
    }
    
    // 更新事件的初始计数
    raidEvent.RaidInitialCount = _maxObservedHostileCount;
}
```

**工作流程**：
1. 袭击事件触发 → 开始监控
2. 每秒检查敌人数量 → 记录最大值
3. 第一个敌人死亡/倒地 → 锁定初始计数
4. 战斗结束 → 输出准确的战斗报告

### 3. 智能袭击类型识别

```csharp
// Source/Services/RaidTrackingService.cs
public static (string threatName, string unitName) GetRaidTypeDisplayNames(string title)
{
    if (IsAnimalRaidEvent(title)) return ("发狂动物", "只");
    if (IsInfestationEvent(title)) return ("虫群", "只");
    if (IsMechanoidEvent(title)) return ("机械族", "个");
    return ("敌人", "人");
}
```

**识别关键词**：
- 动物袭击：manhunter, animal, 猎杀, 动物, 发狂
- 虫群袭击：infestation, insect, 虫害, 虫群
- 机械族：mechanoid, mech, cluster, 机械

### 5. 战斗报告生成

```csharp
// Source/Services/RaidTrackingService.cs
public static string FinishRaidTracking(ColonyAnnouncement raidEvent)
{
    var report = new StringBuilder();
    report.Append("[战斗结束] ");
    
    var (threatName, unitName) = GetRaidTypeDisplayNames(raidEvent.Title);
    
    // 敌方统计
    if (raidEvent.RaidKillCount > 0)
        enemyStats.Add($"击杀{raidEvent.RaidKillCount}{unitName}");
    if (raidEvent.RaidDownedCount > 0)
        enemyStats.Add($"击倒{raidEvent.RaidDownedCount}{unitName}");
    if (raidEvent.RaidFleeCount > 0)
        enemyStats.Add($"逃跑{raidEvent.RaidFleeCount}{unitName}");
    
    report.Append($"{threatName}(共{raidEvent.RaidInitialCount}{unitName}): ");
    report.Append(string.Join(", ", enemyStats));
    
    // 我方统计
    // ...
    
    return report.ToString();
}
```

## 开发历程

### 问题 1：发狂动物不被追踪

**发现**：日志显示 `Faction: No Faction, Humanlike: False, IsEnemy: False`

**原因**：原代码只检查 `Humanlike && Faction != null`

**解决**：使用 `pawn.HostileTo(Faction.OfPlayer)`
- 自动处理派系敌对
- 自动处理 `MentalState.Manhunter`
- 自动处理狂暴状态

### 问题 2：空投时初始计数为 0

**发现**：敌人逐个空投，计数时只有部分落地

**原因**：袭击事件触发时，敌人还在空投中

**解决**：
1. 每秒调用 `PeriodicUpdate()` 更新计数
2. 使用最大值策略：只增加不减少
3. 一旦有战斗发生，锁定计数

### 问题 3：倒地后死亡的敌人不被识别为击杀

**发现**：日志显示 `IsEnemy: False`（倒地后 `HostileTo()` 返回 false）

**原因**：倒地的敌人不再被视为威胁

**解决**：三重判断
```csharp
bool isEnemy = isHostileNow || wasDownedEnemy || isHostileFaction;
```

### 问题 4：Lord.ownedPawns 统计不准

**发现**：Lord 报告 12 人，但实际只有 7 人

**原因**：`ownedPawns` 包含了还未落地或状态异常的 Pawn

**解决**：完全放弃 Lord 统计，只使用 `CountHostileThreats()` 的最大值

## 配置选项

在 Mod 设置中可以配置：
- `AutoCompleteRaidEvents` - 是否自动完成袭击事件
- `RaidCheckDelay` - 战斗结束检测延迟（秒）
